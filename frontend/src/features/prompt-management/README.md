# 提示词管理前端

页面入口为 `/admin/prompts` 和 `/admin/prompts/[definitionId]`，复用根集成的 `AdminRoute` 与 `AdminShell`。普通用户被角色边界阻止后，页面组件及正文查询不会挂载。后端仍负责真实角色与对象权限检查。

## 职责

- `api.ts` 只封装实际 OpenAPI 生成的13个管理员接口，并复用共享响应解包和 `ApiError`。类型从生成SDK导出，不维护第二套后端DTO。
- `queries.ts` 维护定义、版本、比较基准、预览、评测和审计的分层Key。请求使用 `no-store`，Query/Mutation无人观察时零时长回收；取消signal传给真实SDK。范围清理先同步删除旧缓存，再等待取消，避免误删下一页面新建的缓存。
- 页面只展示真实注册定义；正文、变量、依赖、合成预览与未保存草稿都仅留在当前组件/会话内存。没有存储恢复、正文URL参数、自动模型调用或新建空Agent入口。
- 版本编辑以读取时的修订和草稿创建时活动版本为基准。409保留输入且不重发；重新加载是显式放弃/重新读取操作。发布、回滚、启停有明确确认。回滚必须填写原因，使用服务器返回的新版本ID，历史ID不重新激活。
- 合成预览不调用模型；固定评测仅由管理员点击触发，显示完整指纹、模型配置、逐样例结果和失败门禁。最终发布资格由服务器按完整指纹验证。

## 设计与验收边界

本机未找到Prompt列表/详情完整Pen稿。用户已在本批明确授权依照现有后台54/55截图、象牙白/阳光黄/浅沙色视觉规范与已批准OpenSpec补齐本期状态。页面复用已安装shadcn组件，没有宣称Pen逐像素验收。

未保存草稿在版本切换、页面返回/共享导航链接和浏览器硬离页时提示。本地Next官方文档与App Router实现确认没有可取消历史跳转的beforePopState接口，因此不添加改写历史栈的哨兵。`PromptDraftScope`须由根管理员layout置于`AdminRoute`内、`AdminShell`外：在当前后台认证会话内保存React内存镜像，Back/Forward返回时恢复输入及原修订；显式放弃/保存清除对应镜像，离开后台、登出或角色失效卸载scope时同步清空。没有使用浏览器持久化存储，无法承诺跨后台或跨页面刷新恢复。真实浏览器角色矩阵、交互截图、长正文与响应式视觉核验由根集成执行，组件测试不能代替这些验收。

本分支未调用真实在线模型、未迁移业务库、未运行生产构建、未推送或部署。共享Scope wrapper由根集成负责，范围组件和恢复/清理回归在本目录交付。模型评测测试使用合成响应，不等于真实模型通过证据。
