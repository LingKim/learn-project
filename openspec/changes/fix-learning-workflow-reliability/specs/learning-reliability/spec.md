# 学习闭环可靠性修正

## ADDED Requirements

### Requirement: 既有学习操作保持版本与失败约束

系统 SHALL 按已批准练习与学习资产规格保持最新已保存答案、当前路由对象、明确不可重试失败、复习追加历史和失效来源缓存的正确行为，不新增产品规则。

#### Scenario: 提交等待保存期间再次输入
- **WHEN** 用户在答案保存等待期间继续编辑并提交
- **THEN** 系统提交最终已确认保存的答案版本，不提交陈旧版本

#### Scenario: 当前练习链接改变
- **WHEN** 同一页面组件收到新的练习和任务参数
- **THEN** 系统读取当前链接的任务，不继续查询旧任务

#### Scenario: 执行器禁止重试
- **WHEN** 失败被执行器标记 retryable=false
- **THEN** 失败任务保持不可重试；来源、版本及取消禁令仍可否决重试

#### Scenario: 来源恢复
- **WHEN** 已有复习来源从可用变失效后恢复至同一版本
- **THEN** 新可用结论追加到历史，连续重放相同状态不重复追加

#### Scenario: 来源接口不可用
- **WHEN** 来源接口返回不存在或已失效的 404
- **THEN** 前端清除对应原文 Query 缓存

#### Scenario: 退出或切换账号
- **WHEN** 登录状态或用户身份改变
- **THEN** 系统更换私有 QueryClient 与页面状态，旧查询或 mutation 只能持有退出会话的旧 client

#### Scenario: 离开页面后收到迟到响应
- **WHEN** 用户离开某轮练习或精讲，原请求随后返回
- **THEN** 原请求不能导航回旧页面、修改新页面状态或继续提交后续操作
