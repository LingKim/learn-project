# prompt-management Specification

## Requirements

### Requirement：只有真实注册的 Agent 场景可以被纳管

系统 SHALL 由代码注册 Agent/scene 的输入上下文 Schema、输出 Schema、工具 allowlist、执行器以及所需公共/Agent 片段；管理员只能为已经注册且真实可执行的任务场景创建、发布和启用任务 Prompt，公共/Agent 片段必须至少被一个注册场景声明使用。

#### Scenario：创建已注册场景的定义

- **WHEN** 管理员为注册表中存在的 Agent/scene 创建 PromptDefinition
- **THEN** 系统绑定稳定 key 和代码契约
- **AND** 允许进入草稿流程

#### Scenario：创建未知或空场景

- **WHEN** 管理员提交未注册 Agent、未注册 scene 或缺少执行器/Schema 的定义
- **THEN** 系统返回稳定校验错误
- **AND** 不创建可发布定义或占位模板

#### Scenario：创建无人使用的公共片段

- **WHEN** 管理员创建未被任何注册场景声明依赖的公共或 Agent 片段
- **THEN** 系统返回稳定校验错误
- **AND** 不把孤立片段加入管理与运行装配

#### Scenario：历史定义已从代码退役

- **WHEN** 数据库定义已产生历史运行记录但当前注册表不再包含该场景
- **THEN** 系统允许管理员只读查看历史版本和运行引用
- **AND** 禁止新建草稿、发布或启用该定义

### Requirement：Prompt 必须按职责和任务场景分层组合

系统 SHALL 使用全局公共规则、Agent 角色规则和任务场景规则的确定顺序装配消息，并由代码注入输出 Schema 和工具权限，不得使用一个大一统模板替代全部角色。

#### Scenario：装配任务 Prompt

- **WHEN** 已注册 Agent 场景启动一次运行
- **THEN** 系统按 `global → agent → task` 顺序加载已发布版本
- **AND** 输出 Schema 和工具 allowlist 来自代码注册表
- **AND** 生成确定的版本与哈希列表

#### Scenario：Prompt 尝试扩大工具权限

- **WHEN** 模板正文或用户数据要求调用注册表未允许的工具
- **THEN** 执行器不会向模型暴露该工具
- **AND** Prompt 内容不能改变业务状态机或权限检查

### Requirement：公共片段必须固定不可变依赖

系统 SHALL 在根 Prompt 版本发布时保存公共/Agent 片段的具体版本、slot、顺序和哈希，不得在运行时动态解析“最新公共模板”。

#### Scenario：公共规则发布新版本

- **WHEN** 公共片段从 v2 发布为 v3
- **THEN** 依赖 v2 的既有任务版本和历史 AgentRun 继续解析到 v2
- **AND** 只有重新创建、评测并发布的根版本可以依赖 v3

#### Scenario：依赖草稿或循环关系

- **WHEN** 根版本依赖草稿、未知版本、重复 slot 顺序或形成循环
- **THEN** 系统拒绝保存或发布该依赖关系
- **AND** 不产生部分可用的活动版本

### Requirement：变量必须遵循代码契约和安全模板语法

系统 SHALL 只允许模板引用注册上下文 Schema 中的白名单变量，并校验类型、必填、最大长度、来源、敏感级别和显式默认值；模板不得执行表达式、函数、路径遍历、Include 或脚本。

#### Scenario：合法变量渲染

- **WHEN** 合成或运行数据满足注册类型、长度和必填约束
- **THEN** 系统使用受控序列化器渲染简单占位符
- **AND** 数组和对象不会被当作模板代码再次解释

#### Scenario：未知或缺失变量

- **WHEN** 模板引用未知变量、缺少必填变量或声明未注册字段
- **THEN** 草稿预览和发布校验失败并返回字段级错误
- **AND** 不调用模型

#### Scenario：可执行模板载荷

- **WHEN** 模板包含函数、属性遍历、环境变量、远程 Include、循环或脚本语法
- **THEN** 解析器拒绝该模板
- **AND** 不执行载荷或泄露运行环境信息

### Requirement：个性化上下文必须按字段和固定优先级解析

系统 SHALL 由代码场景契约声明每个字段允许的来源，并按 `request > selected_asset/weakness > profile > default` 的顺序逐字段补全；本次选择的 Resume、JD 或 Weakness 只提供场景注册允许的字段，低优先级不得覆盖已决定值。

#### Scenario：本次输入覆盖默认画像

- **WHEN** 用户画像目标岗位为 Java 工程师且本次请求显式填写前端工程师
- **THEN** 本次字段使用前端工程师并记录来源 `request`
- **AND** 画像中的 Java 工程师不进入该字段的运行上下文

#### Scenario：本次选择资产补充字段

- **WHEN** 请求未填写岗位等级但本次选择的 JD 提供已注册且合法的等级约束
- **THEN** 系统使用该资产值并记录来源 `selected_asset` 及 JD 版本引用
- **AND** 更低优先级画像不得覆盖该值

#### Scenario：画像和薄弱点兜底

- **WHEN** 请求与本次资产都未决定目标技能，场景允许 UserProfile 和已选活动 Weakness 提供对应字段
- **THEN** 系统只对各自允许的字段使用 `profile` 或 `weakness` 来源
- **AND** 不从无证据自由文本推断系统薄弱点

#### Scenario：使用场景默认值

- **WHEN** 更高优先级来源均未提供可选字段且场景契约声明显式默认值
- **THEN** 系统使用该值并记录来源 `default`
- **AND** 模型不能自行创造未声明的用户事实默认值

### Requirement：省略、显式 null 与必填缺失必须有确定语义

系统 SHALL 保留请求字段存在性：省略允许继续向低优先级来源兜底，显式 `null` 表示本次禁止该字段兜底；解析后必填字段仍缺失时 SHALL 在模型调用前进入追问状态或返回稳定缺失字段错误。

#### Scenario：省略字段允许画像兜底

- **WHEN** 用户请求省略目标岗位且 UserProfile 存在合法目标岗位
- **THEN** 系统使用画像值并记录来源 `profile`

#### Scenario：显式 null 禁止兜底

- **WHEN** 用户请求显式传入 `target_job=null` 且画像存在目标岗位
- **THEN** 本次目标岗位保持为空并记录本次禁用语义
- **AND** 系统不使用画像或场景默认值补回

#### Scenario：必填信息仍缺失

- **WHEN** 所有允许来源均未提供场景必填字段或被显式 null 禁用
- **THEN** 系统返回缺失字段列表或产品定义的补充信息请求
- **AND** 不调用模型猜测用户岗位、等级、技能或薄弱点

### Requirement：用户内容必须与系统指令隔离

系统 SHALL 将用户画像、资料、简历、JD、回答和转写按不可信数据消息或工具结果处理，不得直接拼接为系统规则，也不得仅依赖特殊字符过滤防护 Prompt Injection。

#### Scenario：资料包含恶意指令

- **WHEN** 用户资料声称需要忽略系统指令、泄露密钥或调用未授权工具
- **THEN** 该内容只作为受长度和类型限制的数据传入
- **AND** 系统规则、工具 allowlist、输出 Schema 和用户权限保持不变

#### Scenario：用户数据超出边界

- **WHEN** 数据长度、数组项目数或嵌套深度超过场景限制
- **THEN** 系统在模型调用前返回稳定校验错误或按明确策略截断
- **AND** 日志和错误不回显完整用户内容

### Requirement：版本生命周期必须不可变且并发安全

系统 SHALL 为每个定义使用独立整数递增版本和 `draft | published | retired` 状态；草稿可编辑，已发布和已退役版本不可修改或删除，同一定义最多一个活动发布版本。

#### Scenario：发布有效草稿

- **WHEN** 管理员发布评测通过且基准活动版本仍匹配的草稿
- **THEN** 系统在短事务中退役旧版本并发布新版本
- **AND** 更新活动指针、发布人和发布时间

#### Scenario：并发发布冲突

- **WHEN** 两个草稿基于同一活动版本且其中一个已经先发布
- **THEN** 后一个发布返回 409 `PROMPT_VERSION_CONFLICT`
- **AND** 不覆盖较新的活动版本或自动改写草稿基准

#### Scenario：修改已发布版本

- **WHEN** 管理员尝试编辑或删除已发布/退役版本
- **THEN** 系统拒绝操作
- **AND** 历史 AgentRun 仍能解析原版本与哈希

### Requirement：发布必须通过版本指纹绑定的固定评测

系统 SHALL 在发布前完成模板、变量、依赖、输出 Schema 和合成固定样例检查，并要求存在与候选内容、依赖、Schema、评测集、模型和参数完全匹配的有效通过结果。

#### Scenario：评测通过并发布

- **WHEN** 管理员显式使用实际配置模型运行已发布合成评测集且全部硬门禁与质量阈值通过
- **THEN** 系统保存逐样例结果、用量、聚合指标和联合指纹
- **AND** 候选版本可以进入发布事务

#### Scenario：评测后修改草稿

- **WHEN** 管理员在评测通过后修改正文、变量或依赖
- **THEN** 旧结果的指纹不再匹配
- **AND** 发布被拒绝直到新指纹重新评测通过

#### Scenario：使用真实用户资料作为固定样例

- **WHEN** 管理员尝试把生产用户资料、简历、JD、回答或转写保存到评测集
- **THEN** 系统拒绝或阻止其进入固定评测数据
- **AND** 评测集只接受合成或经过独立脱敏审查的数据来源

### Requirement：回滚必须产生新的审计版本

系统 SHALL 从曾发布的目标版本及其固定依赖复制出新的递增版本，记录回滚来源、原因和操作者，不得重新激活或修改历史版本。

#### Scenario：回滚到已知稳定版本

- **WHEN** 管理员选择历史 v3、填写原因并基于当前 v5 发起回滚
- **THEN** 系统创建内容和依赖等同 v3 的新 v6，并记录 `rollback_from_version_id=v3`
- **AND** v3、v5 及其历史 AgentRun 保持不变

#### Scenario：回滚证据仍匹配

- **WHEN** v3 的内容、依赖、Schema、评测集、模型和参数指纹仍与当前运行条件一致
- **THEN** 系统可以复用原有效通过证据并原子发布 v6

#### Scenario：回滚条件已经变化

- **WHEN** 当前模型、参数、评测集或代码 Schema 与 v3 原通过条件不一致
- **THEN** 系统只创建 v6 草稿并要求重新评测
- **AND** 不以“历史曾通过”为由绕过当前门禁

### Requirement：停用只控制新运行

系统 SHALL 提供定义级启停安全开关，停用只阻止新的 AgentRun，运行中的任务继续使用启动快照；强制取消必须由对应业务任务状态机执行。

#### Scenario：停用后创建新任务

- **WHEN** 场景已被管理员停用且用户发起需要该 Agent 的新任务
- **THEN** 系统返回稳定不可用结果或进入产品已确认的非 Agent 路径
- **AND** 不静默使用其他 Prompt、模型或供应商

#### Scenario：运行中发生停用

- **WHEN** AgentRun 已固化版本后管理员停用定义
- **THEN** 当前运行继续使用原快照
- **AND** Prompt 管理器不直接把业务任务改为失败或取消

### Requirement：每次运行必须固化可追踪快照

系统 SHALL 在 AgentRun 开始时固化根 Prompt、全部依赖版本与哈希、输入/输出契约哈希、供应商、模型参数、字段级上下文来源、输入引用和输出引用；运行期间的发布、回滚、公共片段、画像或资产更新不得改变该快照。

#### Scenario：运行期间发布新版本

- **WHEN** AgentRun 使用 v4 启动后管理员发布 v5
- **THEN** 当前运行及其业务结果仍记录 v4 组合
- **AND** 之后创建的新运行使用 v5

#### Scenario：普通运行日志记录

- **WHEN** AgentRun 成功或失败
- **THEN** 普通日志只记录 ID、版本、哈希、状态、耗时、用量和错误码
- **AND** 不记录 Prompt 正文、渲染后 Prompt、用户正文或模型完整响应

#### Scenario：画像在运行期间更新

- **WHEN** AgentRun 已固化 UserProfile v4 后用户把画像更新为 v5
- **THEN** 当前运行继续使用启动时的 v4 输入引用和字段级来源
- **AND** 后续新运行可以使用 v5

#### Scenario：记录字段级来源

- **WHEN** 一次运行同时使用请求岗位、JD 等级、画像技能、活动薄弱点和场景默认语言
- **THEN** AgentRun 分别记录 `request | selected_asset | profile | weakness | default` 及可用对象版本引用
- **AND** 普通日志和来源快照不复制字段正文或薄弱点证据

### Requirement：Prompt 运行不得自动回写用户画像

系统 SHALL 将 UserProfile 作为只读上下文来源；任务输入、选中资产、模型推断和生成输出不得在 AgentRun 事务或执行器中自动修改画像。

#### Scenario：模型推断用户等级

- **WHEN** 模型输出推测用户可能属于高级岗位等级
- **THEN** 系统只把它作为当前业务结果按对应领域规则处理
- **AND** 不更新 UserProfile.target_level

#### Scenario：任务使用临时技能

- **WHEN** 用户本次指定了画像中不存在的技能
- **THEN** 当前 AgentRun 使用并记录请求来源
- **AND** 运行成功或失败都不把技能写入默认画像

#### Scenario：用户明确保存为默认画像

- **WHEN** 用户在业务页面主动选择明确字段并确认保存
- **THEN** 客户端调用独立个人资料 API 并携带资料乐观锁版本
- **AND** Prompt 管理器不绕过资料权限、校验或冲突处理

### Requirement：内容复原必须区分历史读取与模型重跑

系统 SHALL 通过版本化业务对象精确返回历史题目、报告、笔记和学习计划；模型重跑只能在数据与权限仍有效时创建新 AgentRun 和新业务版本，不得覆盖历史或承诺字节一致。

#### Scenario：查看历史结果

- **WHEN** 用户查看仍在保留期且属于自己的历史业务版本
- **THEN** 系统直接返回已保存结果
- **AND** 不重新调用模型生成替代内容

#### Scenario：按历史快照重跑

- **WHEN** 用户有权访问全部输入且请求按历史执行条件重新生成
- **THEN** 系统使用可用的历史 Prompt/依赖/模型参数快照创建新运行
- **AND** 保存为新的业务版本并明确可能与历史结果不同

#### Scenario：来源已删除或权限已撤销

- **WHEN** 历史输入已删除、过期或当前用户无权访问
- **THEN** 系统拒绝重跑
- **AND** 不从日志、管理员 Prompt 页面或其他用户数据恢复正文

### Requirement：Prompt 正文只能通过管理员专用无缓存接口访问

系统 SHALL 只允许管理员通过专用编辑接口读取 Prompt 正文，并对正文详情、预览和 Diff 响应设置禁止缓存；普通用户、业务 API、运行详情、质量工单、日志和错误不得返回正文。

#### Scenario：管理员查看版本正文

- **WHEN** 已认证管理员打开单个 PromptVersion 详情
- **THEN** 系统返回受控正文并设置 `Cache-Control: no-store`
- **AND** 记录不含正文的敏感查看审计

#### Scenario：普通用户请求正文

- **WHEN** 普通用户、未认证请求或业务结果接口尝试读取 Prompt 正文
- **THEN** 系统拒绝且不泄露目标是否存在
- **AND** 不在响应、错误或日志中包含任何正文片段

#### Scenario：诊断台尝试直接发布

- **WHEN** AI 质量诊断流程产生修复建议并尝试直接修改、发布或回滚 Prompt
- **THEN** 系统拒绝跨域写操作
- **AND** 建议必须进入独立草稿、评测和发布流程

### Requirement：缓存不得成为正确性依赖

系统 SHALL 以 PostgreSQL 为 Prompt 定义、版本、依赖、评测和活动指针的唯一事实源；任何缓存均可丢失且不得保存渲染后的用户 Prompt。

#### Scenario：缓存不可用

- **WHEN** 进程缓存或未来 Redis 不可用
- **THEN** 系统从 PostgreSQL 解析活动版本和不可变正文
- **AND** 发布、回滚和运行快照的正确性不受影响

#### Scenario：活动版本切换

- **WHEN** 发布、回滚或停用事务成功
- **THEN** 系统使活动指针缓存失效
- **AND** 正文缓存仍以不可变版本 ID 和哈希隔离，不覆盖旧版本

### Requirement：管理员 Prompt 操作必须完整审计且不泄露正文

系统 SHALL 对正文查看、草稿创建/修改、预览、评测、发布、回滚、启停和拒绝访问记录操作者、目标、版本、结果、request ID 和时间，不记录 Prompt 或用户正文。

#### Scenario：发布审计

- **WHEN** 管理员成功发布 Prompt 版本
- **THEN** 审计记录定义、旧/新版本、评测运行、操作者和结果
- **AND** 不复制正文、合成样例或模型完整响应

#### Scenario：越权访问审计

- **WHEN** 请求因角色、目标或状态不合法被拒绝
- **THEN** 系统记录不含敏感内容的拒绝事实和稳定原因码
- **AND** 对客户端保持资源存在性不泄露
