# user-profile Specification

## Requirements

### Requirement：个人资料必须与账户一对一且全部可选

系统 SHALL 为普通用户提供至多一条 `UserProfile`，画像字段全部可选且不作为注册、登录或使用业务功能的前置条件；用户名 SHALL 只读，昵称继续由 `User` 保存。

#### Scenario：首次读取空画像

- **WHEN** 当前普通用户尚无 UserProfile 记录并读取个人资料
- **THEN** 系统返回用户名、昵称、空画像字段和 `version=0`
- **AND** 不强制创建空记录或跳转首次引导

#### Scenario：首次保存画像

- **WHEN** 当前用户携带 `version=0` 提交合法画像字段
- **THEN** 系统原子创建与该用户一对一的 UserProfile
- **AND** 返回递增后的稳定资料版本

#### Scenario：只修改昵称

- **WHEN** 尚无画像的用户只提交合法昵称
- **THEN** 系统更新 User.nickname 并返回统一资料视图
- **AND** 可以不创建没有业务字段的空 UserProfile

### Requirement：画像字段必须使用稳定契约和规范化规则

系统 SHALL 校验目标岗位、工作年限月数、岗位等级、目标技能、重点关注知识点、学习目标和默认语言的类型、长度、数量与枚举，并对标签进行去空白、去空项和稳定去重。

#### Scenario：保存合法画像

- **WHEN** 用户提交契约范围内的岗位、月数、等级、标签、目标和语言
- **THEN** 系统保存规范化值
- **AND** 响应返回相同语义的稳定字段

#### Scenario：提交超限或未知枚举

- **WHEN** 月数为负数或超限、标签数量/长度超限、岗位等级或语言不在允许枚举
- **THEN** 系统返回字段级稳定校验错误
- **AND** 不产生部分更新

#### Scenario：标签包含重复和空白

- **WHEN** 用户提交大小写与空白规范化后重复的技能或关注知识点
- **THEN** 系统按已声明规则稳定去重并保持首次出现顺序
- **AND** 不保存空字符串项目

### Requirement：工作年限必须只保存月数并统一展示

系统 SHALL 仅持久化非负整数 `experience_months`，并由后端序列化器生成用户可读描述，不得持久化或接受第二份可漂移的年限描述。

#### Scenario：整年工作年限

- **WHEN** 画像保存 `experience_months=24`
- **THEN** 资料响应返回 24 和“2 年”

#### Scenario：年与月组合

- **WHEN** 画像保存 `experience_months=30`
- **THEN** 资料响应返回 30 和“2 年 6 个月”

#### Scenario：客户端提交描述字段

- **WHEN** 客户端尝试提交自定义工作年限描述
- **THEN** 系统拒绝未知或只读字段
- **AND** 不用客户端文案覆盖服务端展示规则

### Requirement：资料部分更新必须区分省略与显式清空

系统 SHALL 对 `PATCH` 请求使用字段存在性语义：省略字段保持原值，显式 `null` 清空可空标量或数组，显式空数组清空标签；用户名不可修改。

#### Scenario：省略字段

- **WHEN** 用户只提交目标岗位和当前版本
- **THEN** 系统只更新目标岗位
- **AND** 其他画像字段保持不变

#### Scenario：显式清空字段

- **WHEN** 用户把学习目标传为 `null` 或目标技能传为空数组
- **THEN** 系统清空对应字段
- **AND** 不从旧值或其他来源自动补回

#### Scenario：尝试修改用户名

- **WHEN** 资料更新请求包含用户名
- **THEN** 系统返回稳定只读字段错误
- **AND** 账户用户名保持不变

### Requirement：资料更新必须使用乐观锁防止静默覆盖

系统 SHALL 要求资料写操作携带当前 `version`，并在同一事务比较和递增版本；陈旧版本 SHALL 返回 409 `PROFILE_VERSION_CONFLICT`。

#### Scenario：版本匹配更新

- **WHEN** 请求版本等于数据库当前资料版本
- **THEN** 系统提交全部合法修改并把版本递增一次

#### Scenario：多设备陈旧更新

- **WHEN** 另一设备已经更新资料且当前请求仍携带旧版本
- **THEN** 系统返回 409 `PROFILE_VERSION_CONFLICT` 和最新版本摘要
- **AND** 不覆盖已提交的新资料

#### Scenario：昵称与画像事务失败

- **WHEN** 同时更新昵称和画像时任一字段或版本校验失败
- **THEN** 两部分均不提交
- **AND** 不产生昵称已变而画像失败的部分状态

### Requirement：系统薄弱点必须保持独立证据模型

系统 SHALL 从当前用户的 `Weakness` 领域对象投影活动薄弱点，不得在 UserProfile 保存无证据的弱项列表，也不得允许自由文本冒充系统识别结果。

#### Scenario：存在活动薄弱点

- **WHEN** 当前用户拥有满足活动状态规则且有证据的 Weakness
- **THEN** 资料响应返回其 ID、名称、来源摘要、严重程度、掌握状态和最后验证时间
- **AND** 不复制到 UserProfile 持久化字段

#### Scenario：薄弱点领域尚未实现或没有数据

- **WHEN** 系统尚无可用 Weakness 查询或当前用户无活动薄弱点
- **THEN** 资料响应返回空集合
- **AND** 不创建占位、推断或默认薄弱点

#### Scenario：提交自由文本薄弱点字段

- **WHEN** 客户端尝试通过资料更新写入 `weak_topics` 或类似系统诊断字段
- **THEN** 系统返回未知字段错误
- **AND** 不创建 Weakness 或画像副本

### Requirement：任务临时值不得自动回写默认画像

系统 SHALL 把 UserProfile 视为只读兜底来源；题目、面试、计划或模型运行中的临时字段和推断结果不得隐式修改画像。

#### Scenario：任务使用临时岗位

- **WHEN** 用户在一次模拟面试中填写与默认画像不同的岗位
- **THEN** 本次任务使用临时岗位
- **AND** UserProfile 保持不变

#### Scenario：用户主动保存为默认画像

- **WHEN** 用户明确选择需要保存的字段并确认“保存为默认画像”
- **THEN** 客户端通过独立资料更新 API 提交字段和资料版本
- **AND** 只有明确选择且通过乐观锁的字段被更新

#### Scenario：保存默认画像发生冲突

- **WHEN** 业务任务创建成功但随后资料更新因陈旧版本冲突
- **THEN** 业务任务保持已创建
- **AND** 系统提示用户重新加载资料后决定是否再次保存默认值

### Requirement：个人资料必须严格隔离且对管理员不可见

系统 SHALL 只允许当前普通用户读取或修改自己的画像；管理员账户列表、账号详情、质量工单、普通运行详情和日志不得返回画像或活动薄弱点内容。

#### Scenario：本人访问资料

- **WHEN** 已认证 active 普通用户读取或修改自己的资料
- **THEN** 系统按当前用户身份处理且不接受客户端所有者覆盖

#### Scenario：跨用户或管理员访问

- **WHEN** 其他用户或管理员尝试通过猜测 ID、文件引用或非公开路径读取画像
- **THEN** 系统拒绝且不泄露目标是否存在
- **AND** 记录不含画像正文的拒绝审计

#### Scenario：管理员查询用户列表

- **WHEN** 管理员读取账户管理列表或详情
- **THEN** 响应只包含 PRD 允许的账号基本信息
- **AND** 不包含头像、岗位、年限、等级、技能、目标、关注点或薄弱点

### Requirement：资料删除和账号状态必须即时影响访问

系统 SHALL 在账号禁用、会话撤销或账号软删除后拒绝个人资料访问；账号删除 SHALL 使画像退出正常查询并触发头像清理流程。

#### Scenario：账号被禁用

- **WHEN** 用户账号被管理员禁用后使用旧 Access Token 请求资料
- **THEN** 系统按认证规则拒绝请求
- **AND** 不返回缓存的个人资料

#### Scenario：用户删除账号

- **WHEN** 用户完成再次验证并删除账号
- **THEN** UserProfile 不再出现在正常查询或 Agent 上下文中
- **AND** 头像引用进入受控清理流程

#### Scenario：普通日志记录资料操作

- **WHEN** 资料读取、更新或删除成功或失败
- **THEN** 日志只记录 ID、动作、状态、版本、耗时和稳定错误码
- **AND** 不记录岗位、技能、学习目标、薄弱点正文或完整请求体
