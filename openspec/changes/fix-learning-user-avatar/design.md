# 修复设计与验收

## 原因核验

诊断优先级为：1.聊天渲染未接入头像；2.资料缓存未更新；3.鉴权读取失败。真实LearningPage组件在有效头像资料与Blob已存在缓存的情况下仍显示默认图标，且其用户消息区域直接渲染UserRound，确认首项原因。现有个人资料页面已经提供头像查询、Blob ObjectURL生命周期管理，上传后使user-profile缓存失效，删除后清除头像缓存并更新资料。

## 实现

在学习室复用现有feature Query配置读取当前用户资料和头像，通过ObjectURL展示，头像变更和卸载时释放URL；读取失败或图像加载失败回退现有UserRound。仅改现有消息头像位置，维持size-9圆形、原定位与布局。实现前核对Pen对应的用户消息头像设计，不增加设计范围。

## 验收

- 已设置头像的账号打开历史会话及发送新消息，都显示当前头像。
- 更换头像后再次打开学习室不显示旧图片；现有资料缓存更新时学习室头像同步。
- 删除、未设置、头像读取或图片加载失败时回退默认图标。
- 头像请求沿用鉴权、feature API/Query与共享错误机制，不新增业务接口或重复DTO。
- 自动化测试覆盖上述显示与同步场景；浏览器验证真实账号头像与会话头像一致。
- 不执行build或Git提交推送，不修改其他待批准功能。
