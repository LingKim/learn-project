# Proposal：难点资产与文字知识精讲第一版

## 决策与批准状态

2026-10-03，用户先回复“好的 确认”确认方向；在本期具体范围、默认门槛、状态与验收方案展示后回复“开始开发”，明确批准本文件及design/api-contract规定的方案。当前开始实施；进度与实际验证边界见tasks/evidence。

依据 PRD 7.2.4、7.5、8.1、14.1：现有练习已提供五题型、不可变题集、回答/评分版本和本次知识点报告，缺少跨练习证据、独立 Weakness 与知识卡片。目标闭环为“练习 → 候选薄弱点 → 难点资产 → 文字精讲 → 针对性再练”。

## 本期提议范围

- 从本人练习的有效评分提取候选薄弱点，绑定题目、回答、评分版本与错误依据；采用服务端证据规则，不再调用模型猜测长期能力。
- 一次错误先进入待确认候选，不自动定性。满足明确重复错误门槛的候选自动成为正式难点；其他候选由用户确认或忽略。
- 私有难点列表、搜索/标签/状态筛选、详情、来源证据、状态历史、手动创建/编辑、撤销与软删除。相同模式/知识库/选中文件范围的同名概念精确去重；首版来源范围创建后固定，名称/标签可编辑；本期不自动做语义合并，人工跨概念合并另期实现。
- 正式难点异步生成文字知识卡片；未确认候选不生成。包含概念/适用场景、原理、示例、常见误区与理解练习，重新生成追加版本，失败保留旧卡片。
- 启用学习室“知识精讲”：可输入知识点或选择本人活动难点，设置基础、深度和语言，使用资料/通用模式。直接精讲保存私有结果，不隐式创建难点。
- 从难点或精讲结果发起针对性非限时练习，复用已有配置确认、出题、作答和评分流程，固化难点版本或精讲卡片版本；保留复习记录和再次验证依据。
- 个人资料的活动薄弱点改为读取真实领域对象，任务仅使用用户本次选中的难点，不把全部历史注入上下文，不自动回写画像。
- 本期仅接入练习评分来源及手动创建。问答、面试、简历/JD 等来源待各自可靠识别契约落地后接入。

## 已批准默认值与业务决策

| 项目 | 提议 |
| --- | --- |
| 自动入库 | 最近30天、同一概念/来源范围，至少3道不同中等/困难单知识点题出现有效错误/部分正确，分布在至少2次练习；该概念最近两道有效题也均为错误/部分正确；主观评分不得为低置信度 |
| 单次错误/低置信度 | 作为待确认候选展示实际证据；模型自报 confidence 不作为掌握概率，不单独触发自动入库 |
| 严重度 | 默认“中”，用户可改高/中/低；不把答错次数转换为未经验证的严重度分数 |
| 掌握状态 | 待学习 → 学习中 → 待验证 → 已掌握；用户可显式调整，保存操作者和原因类型 |
| 系统验证 | 完成关联练习后，相关单知识点题总数至少3道且每道均提交、有效评分、全部正确、无低置信度时记录“本次验证通过”，由用户决定是否标记已掌握；不剔除未答/未评分题后虚报通过 |
| 再次错误 | 针对性练习出现有效错误/部分正确时，待验证/已掌握难点回到学习中；仅未答、评分失败或低置信度不触发自动回退 |
| 精讲默认 | “知道概念＋系统掌握”，语言沿用显式输入/画像/中文兜底；基础与深度可修改 |
| 模型与任务 | 沿用当前学习模型 Settings（当前默认 qwen3.8-flash）、非思考结构化输出；独立持久化 knowledge-worker，默认并发 2、30 秒租约、180 秒任务上限 |
| 针对性练习 | 首版一次选择一个难点或精讲卡片目标，默认仍为5题/中等；允许沿用现有五题型与1–20题配置，不增加计时或正式测评 |

门槛是已批准的首版产品策略，实施后需保存策略版本并通过边界样例验证。它们不来自已校准的统计结论；更改策略不静默扫描/重算全部旧记录。

## 非目标与后续顺序

不交付音频、笔记、学习计划、正式计时测评、简历/JD、语音/真实面试、质量工单、提示词管理台、全局任务中心/通知、导出或代码执行。人工跨概念合并和全部历史自动回填留到后续。沿用现有 AI 使用说明，不新增首次同意弹窗或额外确认仪式；候选确认和原练习配置确认是本期已有产品流程。

本期闭环之后继续质量诊断/提示词管理，再进入简历与模拟面试；正式测评另立方案，不将它并入本次实现。

## 验收标准

1. 新练习有效错误可生成候选；一题重复作答、同题重评、请求重放不累计为不同题。未提交、评分失败、低置信度及缺少逐知识点归因的多知识点题不触发自动入库或系统掌握结论。
2. 满足批准门槛自动入库，否则需用户确认；并发重复事件只产生一个活动资产，同名不同来源范围不自动混成一条。用户忽略的证据不被原事件反复重新提交。
3. 练习来源候选/资产可追溯到实际回答和不可变评分，手动难点可追溯到用户声明/确认快照；重评修正以追加历史表达，不悄悄删除已确认资产、覆盖知识卡片或改写原报告。
4. 正式难点生成五部分文字卡片；资料模式只能用当前合法证据，无充分依据拒绝，不自动切换通用模式。引用定位目标 ≥95%，结构成功率 ≥99%，无充分资料依据正确拒绝率 ≥90%；报告真实分母与人工语义抽样，小型合成样本不冒充生产质量。
5. 难点 → 新练习 → 保存/提交 → 报告 → 难点复习记录完整可恢复；针对性成功验证与再次错误分别遵循批准规则，旧练习/评分/卡片版本保持稳定。
6. 跨用户及管理员读取业务正文为 0 成功；来源删除、移动、活动版本变化、难点撤销/删除及并发编辑期间，不生成、发布或展示失效来源原文。本人已保存业务结果仍按现有历史规则展示，并标记来源不可用。
7. 持久202、响应丢失恢复、幂等、租约/取消/超时/重启/迟到发布、版本冲突和生成失败有真实状态；GET 不调用模型、不写业务数据。
8. FastAPI OpenAPI 为唯一契约，前端使用 feature API/Query/共享 ApiError；逐项核验校准后的 Pen 及 375/768/1024/1440 页面，实际截图、字体、浏览器流程分别记录。
