# 设计与验收

## 当前事实

前端 learning-page.tsx 使用 consentConfirmed 禁用附件与发送，并显示“同意并继续”。后端 LearningService.prepare_answer/publication_guard 和 AttachmentService.upload 校验对应确认记录。因此只隐藏按钮会使未确认用户无法提问或上传。

## 待批准设计

前端移除该确认查询、确认 mutation、提示区域及 consentConfirmed 对交互的限制。后端仅解除学习室回答与聊天附件的确认记录检查；保留身份、权限、附件合法性和来源复核。不得自动确认或写入虚假同意记录。现有确认接口及记录暂保留，以避免扩大到接口删除和数据库迁移。内容库文档处理逻辑不在本次范围。

依据现有 Pen 学习室设计移除提示区，不调整其他布局或添加替代交互。

## 验收标准

1. 学习室不再显示“同意并继续”以及其说明、加载或错误提示。
2. 没有学习室确认记录的账号仍可文字提问、上传图片/文档、发送并获取回答。
3. 上传或发送不产生新的同意记录；已有记录不被删除。
4. 登录、附件所有权、格式/大小、来源复核仍有效；内容库流程不变。
5. 更新相关前后端测试、OpenSpec任务状态，执行必要检查及浏览器验收，不执行build或Git提交推送。
