# Proposal：学习刷题练习第一版

## 决策与状态

2026-10-03 用户在具体方案展示后明确回复“确认方案 开始开发”，本期范围、默认值、设计和验收标准已批准。当前正在实现与验证，实际进度及验收边界见 tasks.md / evidence.md。

依据 PRD 7.2、8.1.3、12、14.1：目前已有资料检索和快速问答，缺少测量掌握程度的练习。成功终点是用户基于本人资料或指定知识点创建题目、作答、获得可解释点评，并能重新打开自己的练习记录。

## 本期范围（已批准）

- 在学习室启用“刷题评测”，本期提供非限时练习模式。
- 来源为一个本人知识库及可选文件，或通用知识点；暂不接入尚未实现的简历、JD、Weakness 和聊天临时附件。
- 配置知识点、可选岗位/技能/目标能力、题型、难度、题量；读取现有默认画像，按字段保留显式清空，禁止自动回写画像。
- 支持单选、多选、判断、简答和文本型编程题。默认题量 5、允许 1–20 题，默认中等难度；这是用户已确认的本期产品配置。文本编程题不执行代码。
- 多选按集合完全匹配判分；主观点评 confidence < 0.7 标为低置信度并允许重评。这两项为已确认的首版默认规则，不把模型置信度当校准概率。
- 配置建议与二次确认、题目预览、编辑/删除/单题或整组重新生成；开始答题使用已确认题集版本。
- 答案暂存、继续练习、逐题提交反馈和再次作答；客观题确定判分，主观题展示规则、回答证据、置信度与改进建议。
- 私有历史、题集与答题/评分版本、汇总报告、题目/点评“有帮助/无帮助”记录；不声称反馈已进入质量工单或训练闭环。
- 模型操作采用持久化异步任务，立即返回任务编号；在练习页展示阶段、取消和明确重试，不增加全局任务中心或通知功能。
- 同步合成四格式资料出题、来源可定位与无答案拒绝的评测；保留旧链路的未验收项，不把它们全部冒充本期交付。

## 后续顺序

1. 本变更：资料/通用知识练习闭环。
2. 新独立变更：正式测评（计时、题目锁定、断点续答、到时提交、评分版本）与难点资产/文字精讲，具体拆分再确认。正式测评与练习共用题集和评分基础。
3. 接续已有质量反馈诊断台和提示词管理 OpenSpec，重新核对依赖与旧 evidence。
4. 简历分析与模拟面试；笔记、音频、计划继续遵循 PRD 分期。

## 非目标

本次不交付计时正式测评、自动薄弱点入库、知识精讲、音频、笔记、学习计划、简历/JD、在线代码沙箱、公共题库、模板收藏、新任务中心、通知或完整管理员控制台。不增加新的首次 AI 同意弹窗，沿用当前说明与既有资料解析授权边界。

## 验收标准

1. 本人资料和通用知识都能完成配置确认、题目预览、练习、逐题反馈、历史恢复；刷新后已确认保存的答案与点评保持一致。
2. 五种题型结构有效；重复题、非法答案/选项、缺失评分规则、数量不匹配和伪造来源不能进入可开始题集。修改题目必须同步验证答案及评分规则。
3. 客观题按已保存规则确定判分；主观题有实际回答证据、维度、置信度与建议，未提交的答案不能伪装为已评分，规则不完整时不展示数值总分。再次作答和重评保留旧版本。
4. 跨用户和管理员业务正文访问为 0 成功；资料删除、移动或活动版本变化后不发布陈旧引用或继续使用失效原文。历史题目和答案仍可读取，来源预览失效明确标记。
5. 四格式合成资料含原生、扫描与混合 PDF。检索 Recall@5 ≥ 90%，来源定位完整率 100%；出题有效结构成功率 ≥ 99%，生成结果引用可定位率 ≥ 95%，无充分资料依据正确拒绝率 ≥ 90%。样例数量、实际分母、失败样例和人工抽样单独记录，小型合成集不代表生产分布。
6. 重复请求、模型失败/超时、租约过期、并发编辑/保存、来源撤权、重新生成失败均有稳定行为；已有有效题目、答案、评分不被失败操作覆盖。
7. FastAPI OpenAPI 与生成 SDK 一致；前端统一 feature API/Query/ApiError 接入；真实接口及隔离浏览器流程验证，并逐项对照校准后的 Pen。

## 风险与依据

- 检索层已有小型 TXT 评测的无答案正确率为 0。生成时必须增加结构化证据不足结果及后端引用校验，不能把相似分数当充分证据；未经人工核查的引用不能证明答案受资料支持。
- 现有 Prompt 是代码不可变版本组合。本期复用此方式并固化运行清单，不冒充数据库提示词管理已实现。
- `BackgroundTask` 当前有非空 file_asset_id 与文件活动任务约束，不能直接承载练习。使用练习自己的持久化执行记录和轻量 practice-worker，不扩大文件 worker；其启停与配置纳入本项目开发运行命令。
- Pen 10–13 已读取图层与截图，包含正式测评、过时导航、笔记/计划/难点入口及答题模式控件裁切问题。已保留原稿并校准新稿 68–76；页面实现逐项依据新稿，实际浏览器验收见 evidence。
- 真实模型验收只使用合成材料；既有用户原件的外发授权不能自动延伸为本次出题评测授权。
