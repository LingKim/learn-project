# Proposal：学习快速回答

## 背景与目标
已有资料解析和受保护检索，尚无用户回答链路。按 PRD 14.1 建立首个学习场景：资料/通用问答、可定位引用、追问和私有会话历史。用户 2026-10-02 授权按推荐顺序实施并指定 qwen3.8-flash。

## 范围
- 先补固定合成中文检索评测、消融 runner 与现有任务状态校准。
- 建立真实 content_analyzer / learning_quick_answer 执行器、代码不可变 Prompt 组合及 AgentRun 元数据。
- 资料模式固定一个知识库、可选多个文件；通用模式标注模型通用知识。每次追问重新检索，历史答案不能充当本次证据。
- 当前用户私有会话、新建、分页列表、详情、自动标题、重命名、软删除；幂等提交和会话级并发控制。
- qwen3.8-flash 非思考模式、严格 JSON Schema、服务端引用白名单、无证据拒答、超时/错误明确反馈。
- /learning 页面、统一生成 SDK 与 Query 接入、来源预览、回答有帮助/无帮助反馈。

## 非目标
不实现笔记、出题、知识精讲、语音面试、管理员 Prompt 管理台或完整质量工单台；不执行生产发布、业务库迁移、Git 提交；不替用户重试既有 PDF。

## 验收
自动测试覆盖模式、越权、撤权、引用伪造、失败重试、重复发送、并发、删除竞态、Prompt 隐私与前端边界。隔离 PostgreSQL 验证迁移和会话；真实千问仅发送合成资料。检索评测报告真实指标，未达标不得宣称生产质量达标。人工文件验收、恢复演练仍单列。
