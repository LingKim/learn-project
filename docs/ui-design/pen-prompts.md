# 学面通 AI - Pen UI 设计提示词记录

> 创建日期：2026-08-23  
> 设计工具：Pen 右下角 Agent 输入框  
> 设计方式：仅通过提示词生成和修改，不直接操作画布元素  
> 需求基线：`docs/学面通AI-产品需求文档.md` v0.10

## 1. 现有设计参考

参考截图：[现有学习室设计](./evidence/01-existing-learning-room.png)

现有稿代表的视觉语言：

- 1440 × 960 桌面 Web 应用；
- 温暖、克制、专注学习的浅色界面；
- 象牙白主背景 `#FBF8F0`，阳光黄作为唯一主要强调色，搭配浅沙色侧栏和深灰文字；
- 顶部品牌导航、左侧上下文侧栏、右侧主要工作区；
- 细描边、小圆角、极轻阴影、线性图标，不使用渐变、霓虹、玻璃拟态或堆叠卡片；
- 对话场景中用户消息靠右，AI 消息靠左；底部采用宽大的多行输入区；
- 整体气质应像安静、可信赖的个人学习书桌，而不是通用 AI 管理后台。

### Prompt 02 - 完整学习模块

```text
继续沿用当前 Pen 文件中「学面通AI·学习室参考稿」和已建立的设计系统，不改变颜色、字体、圆角、描边、导航结构和整体密度。补全学习模块全部 UI。

学习室顶部或内容区首层必须有清晰的三模式选择器：快速回答（默认）、知识精讲、刷题评测。业务模式选择与知识来源选择分开：需要知识来源时，再展示「资料模式 / 通用模式」；资料模式可选择一个知识库和多个文件；通用模式显示“模型通用知识”说明。

创建以下 1440×960 Frame：
1. 学习快速回答空状态：左侧可收起历史会话，主区显示三模式选择器、知识来源选择和宽大的多行输入区；
2. 学习快速回答有对话状态：用户消息在右，AI 消息在左，资料回答带可点击引用；结果操作包含继续追问、反馈、生成笔记；
3. 知识精讲输入状态：知识点/薄弱点选择、当前基础、期望深度、资料/通用来源；
4. 知识精讲结果：结构化知识卡片，包含概念、原理、示例、常见误区、练习；“生成讲解音频”和“生成笔记”都是用户主动按钮；
5. 刷题评测创建：岗位、技术栈、资料、简历、薄弱点、题型、难度、题量、目标能力、是否限时；高级选项渐进展开；
6. AI 二次确认与题目预览：展示 AI 建议的题型/难度/题量，用户确认后可删除、编辑、重新生成题目；
7. 正式答题：题号导航、剩余时间、自动保存、退出后继续说明、提交确认；
8. 评分报告：逐题结果、证据、置信度、改进建议、候选薄弱点；提供进入知识精讲、加入学习计划、主动生成笔记；
9. 学习任务加载/排队状态；
10. 资料不足、生成失败和重试状态。

严格执行笔记规则：任何流程结束都不能自动写入笔记。用户点击「生成笔记」后，先出现笔记预览；用户确认保存后才创建笔记。不要使用“一键自动存入笔记”的文案。

让三个模式看起来属于同一个学习室，但输入结构和结果结构明显不同。完成后检查所有模式入口、主 CTA、次级动作、空状态和失败恢复是否清楚。
```

### Prompt 03 - 完整面试模块

```text
继续沿用现有设计系统和学习室视觉语言，补全「面试间」全部 UI。面试间必须提供五种用户可选业务模式：快速回答（默认）、简历优化、模拟面试、面试复盘、知识精讲。五种模式共享同一面试间框架，但每种模式有独立流程、输入和结果。

创建以下 1440×960 Frame：
1. 面试快速回答空状态与有回答状态：可选资料/通用知识来源，回答展示结构、参考答案和来源说明；
2. 简历与 JD 管理：上传或粘贴、版本列表、解析状态、选择目标 JD；
3. 简历分析：结构完整性、量化程度、岗位匹配、优势、问题、潜在追问点；
4. 简历逐条优化：每条显示原文、建议文本、修改原因、接受/拒绝；
5. 简历版本对比：原始版本与新版本清晰对照，可直接进入模拟面试；不要设计 Word 下载功能，当前需求尚未确认；
6. 模拟面试配置：简历/JD 均可选，也可填写岗位、主题、能力要求；面试类型、难度、10/20/30/45/60 分钟、题量、压力等级、重点能力；
7. 设备检测：麦克风权限、录音、语音识别、扬声器测试和录音保存 7 天说明；
8. 轮次式语音面试进行中：AI 提问、用户语音回答、实时转写、静音结束倒计时、手动结束回答、问题间暂停、面试进度；
9. 断线恢复与暂停超时状态；
10. 模拟面试报告：逐题转写、基础维度和面试类型专属维度、回答证据、薄弱点、改进建议；
11. 转写修正与重新评分版本：原始文本和修正文案区分清楚；
12. 真实面试复盘上传：仅中文普通话、录音用途、第三方处理、7 天保存期限、到期时间和下载能力；
13. 真实面试转写校正：说话人 1/2/3、合并说话人、指定本人/面试官、时间戳；
14. 真实面试复盘报告：问题链、回答、证据、整体表现、薄弱点、建议；
15. 面试知识精讲：针对面试薄弱点的结构化知识卡片、表达建议、按需音频、继续刷题或再次模拟面试；
16. 面试任务处理中、失败和重试状态。

录音未过期时提供下载并显示剩余天数；到期后显示「录音已清理」，不显示失效下载按钮。任何模式都不得自动生成笔记；只提供「生成笔记」按钮、预览和确认保存流程。

视觉上增强面试的专注和临场感，但仍保持温暖浅色体系，不改成深色科技驾驶舱。完成后检查语音状态、计时、暂停、断线恢复、说话人角色和报告证据的可理解性。
```

## 5. 最终验收结果

- Pen 页面集包含 `00–61` 共 62 个编号页面，另保留「学面通AI·学习室参考稿」与面试间五模式公共组件；

- 笔记统一采用“用户主动生成 → 预览 → 确认保存”，未设计自动生成；
